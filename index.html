LNL Uploader

Personal desktop tool for the TikTok account @lnl.vison

What it does

LNL Uploader is a private desktop tool used only by the owner of the TikTok account @lnl.vison. It sends short videos produced on the owner's own computer to the owner's TikTok inbox as drafts, using TikTok's official Content Posting API. The owner then opens each draft in the TikTok app, finishes editing (sound, caption, settings) and decides whether to publish it.

The tool never publishes anything by itself, does not read other users' data and is not offered to the public.

O que é (português)

O LNL Uploader é uma ferramenta pessoal, usada só pelo dono da conta @lnl.vison, que envia vídeos produzidos no próprio computador para a caixa de entrada (rascunhos) da conta no TikTok, pela API oficial. O dono finaliza e publica cada vídeo no app do TikTok.
