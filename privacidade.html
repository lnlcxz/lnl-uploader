Privacy Policy

Last updated: October 26, 2026

Data the tool accesses

  • user.info.basic: the TikTok account's basic profile information (open ID, display name and avatar), used only to confirm which account was authorized.
  • video.upload: permission to send video files to the account's TikTok inbox as drafts.

How data is stored

The access token and refresh token returned by TikTok are stored only in a local file on the operator's own computer. No data is sent to any server other than TikTok's official API. There is no database, no analytics, no advertising and no cookies.

Sharing

No data is sold, shared or transferred to third parties.

How to revoke access and delete data

Access can be revoked at any time in the TikTok app (Settings and privacy > Security > Manage app permissions) or with the tool's revoke command, which also deletes the local token file.

Política de Privacidade

  • A ferramenta acessa só o perfil básico da conta (user.info.basic) e a permissão de enviar vídeos como rascunho (video.upload).
  • Os tokens de acesso ficam apenas num arquivo local, no computador do operador. Nada é enviado a outro servidor além da API oficial do TikTok. Não há banco de dados, análise, anúncios ou cookies.
  • Nenhum dado é vendido ou compartilhado.
  • O acesso pode ser revogado a qualquer momento no app do TikTok (Configurações e privacidade > Segurança > Gerenciar permissões de apps) ou pelo comando de revogação da ferramenta, que também apaga o arquivo local.
